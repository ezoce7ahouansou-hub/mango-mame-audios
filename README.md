# Mango Mame : audios
Application d'écoute des audios du conte bilingue wolof · français « Mango Mame : La mangue de Mame ». © 2026 AHOUANSOU Ezoce.

Application installable (PWA) : l'écran d'accueil impose l'installation, puis les audios se gardent sur le téléphone pour l'écoute sans Internet.

## Publier une nouvelle version
Changer le même numéro à 4 endroits : `VERSION` et `NUM` dans `sw.js`, `version.txt`, et `VERSION_PAGE` dans `index.html`.
Ouvrir `?diag=1` à la fin de l'adresse affiche un récapitulatif technique ; `?test=1` saute l'installation (onglet en cours seulement).
