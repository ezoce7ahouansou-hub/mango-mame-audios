Mango Mame

La mangue de Mame

Comment écouter ?
  1. Ouvrez le livre à la page que vous lisez avec votre enfant (par exemple la page 3).
  2. Ici, appuyez sur le bouton rouge « Écouter la page 3 ».
  3. Vous entendrez l’histoire en wolof, puis un petit silence, puis en français.

Si vous n’entendez rien : montez le volume de votre téléphone et vérifiez qu’il n’est pas en mode silencieux.

Gardez Mango Mame sur votre téléphone. Plus besoin de chercher le lien, et les audios marchent même sans internet.

▼

Gardez Mango Mame sur votre écran d’accueil :

  1. Touchez les trois petits points ⋮ en haut à droite (suivez la flèche).
  2. Touchez « Installer l’application » (ou « Ajouter à l’écran d’accueil »).
  3. Touchez Installer.

Une icône Mango Mame apparaît, comme une application.

Gardez Mango Mame sur votre écran d’accueil :

  1. Touchez le bouton Partager (le carré avec une flèche vers le haut), en bas de l’écran (suivez la flèche).
  2. Descendez, puis touchez « Sur l’écran d’accueil ».
  3. Touchez Ajouter.

Une icône Mango Mame apparaît, comme une application.

Pour mettre Mango Mame sur votre écran, ouvrez cette page dans Safari (iPhone) ou dans Chrome (Android), pas dans WhatsApp ou une autre application. Copiez le lien, puis collez-le dans Safari ou Chrome.
